excerpt: "This project develops a reinforcement learning agent for the puzzle game Block Blast by combining Monte Carlo Tree Search with a neural network policy–value model. The agent uses CNN-based state representations, action masking, and shaped rewards to support long-horizon planning. Experimental results show that the MCTS+NN agent achieves nearly 4× higher average scores than a random baseline, demonstrating the effectiveness of neural-guided search in combinatorial decision-making tasks."
